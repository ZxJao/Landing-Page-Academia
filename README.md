# Landing Page - Academia

Uma landing page moderna e responsiva para academias, desenvolvida para apresentar planos, serviços e incentivar novos alunos a iniciarem sua jornada fitness de forma prática e intuitiva.

## ✨ Funcionalidades

* Design moderno e responsivo.
* Apresentação dos planos e serviços da academia.
* Seção sobre benefícios e diferenciais.
* Compatível com dispositivos móveis.
* Navegação simples e intuitiva.
